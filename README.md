# 우리 세탁실

Node.js 22 이상에서 별도 설치 없이 `npm start`로 실행한 뒤 http://localhost:3000 에 접속합니다.

- 이름 입력 → 세탁기 4대 확인 → 세탁 시작 → 1분 후 회수 대기 → 본인이 회수 완료
- 서버 상태를 1초마다 조회하므로 다른 브라우저와 기기에도 상태가 공유됩니다.
- 동일 세탁기에 동시 요청이 들어오면 먼저 시작한 한 사람만 사용할 수 있습니다.
- 상태는 data/state.json에 저장되어 서버 재시작 후에도 유지됩니다.
- 같은 네트워크의 다른 기기는 서버 PC의 IP 주소와 3000번 포트로 접속합니다. 방화벽 허용이 필요할 수 있습니다.
- 다른 사용자 시연은 별도 브라우저 또는 시크릿 창에서 진행합니다. 같은 브라우저는 저장된 사용자로 다시 접속합니다.
- 이름은 로그인 인증이 아닌 시연용 표시입니다. 회수 권한은 브라우저에 저장한 개인 토큰으로 확인합니다. 브라우저 저장소를 지우면 기존 세탁물 회수 권한을 잃습니다.
- WASH_SECONDS 환경변수는 저장된 설정이 없을 때 초기 세탁 시간을 정합니다. 이후에는 관리자 패널에서 변경합니다.

인터넷 공개 배포 및 정식 계정 기능은 포함하지 않은 첫 구현입니다.

## 관리자

페이지 하단의 관리자 링크 또는 `/admin`으로 접속합니다. 비밀번호는 서버의 `ADMIN_PASSWORD` 환경변수에서 읽습니다. 로컬 `npm start`는 Git에서 제외된 `.env`를 읽습니다. 다른 환경에서는 `.env.example`을 복사해 비밀번호를 설정하거나 환경변수를 직접 등록하세요. 비밀번호가 없으면 관리자 로그인이 비활성화됩니다.

- 세탁 시간은 1~86400초로 지정하며 새로 시작하는 세탁에만 적용됩니다.
- 강제 비우기는 진행 중이거나 회수 대기인 세탁기를 즉시 사용 가능 상태로 변경합니다.
- 모든 관리자 변경 요청은 서버에서 관리자 세션을 검사합니다. 세션은 8시간 후 또는 서버 재시작 시 만료됩니다.
- 상태, 사용자, 세탁 시간 설정은 서버의 `data/state.json`에 함께 저장합니다. 임시 파일 작성 후 교체 방식으로 저장합니다. 단일 서버 프로세스용 구현입니다.

## Render 배포 설정

Node Web Service로 배포하고 시작 명령을 `npm start`로 설정합니다. Node.js 22.17 이상이 필요하며 외부 패키지는 없습니다.

환경변수:

- `ADMIN_PASSWORD`: 사용할 관리자 비밀번호. 로컬 `.env`는 Git에 포함하지 않으므로 Render에서 별도로 입력합니다.
- `DATA_DIR`: 영구 디스크를 연결한 경우 `/var/data/laundry`로 설정합니다. 디스크 마운트 경로는 `/var/data`로 설정합니다.

Render 기본 파일시스템은 임시 저장소이므로 재시작·재배포 시 저장 내용이 사라질 수 있습니다. 재시작 후에도 상태를 유지하려면 유료 서비스의 Persistent Disk가 필요합니다. 무료 서비스에서 영구 보관하려면 별도 데이터베이스로 변경해야 합니다. 현재는 파일 저장 방식입니다.

공식 안내: https://render.com/docs/disks
