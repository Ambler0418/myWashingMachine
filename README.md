# 공동 세탁실

Node.js 22.17 이상에서 `npm start`를 실행한 뒤 http://localhost:3000 에 접속합니다.

- 학번과 이름을 입력한 뒤 세탁기 또는 건조기를 선택하면 해당 종류의 빈 기기 한 대를 10초 동안 배정합니다. 현재 시연은 입력 정보만 사용하며 실제 학생증 인증은 하지 않습니다.
- 배정된 기기는 본인 화면에서 `나에게 배정됨`, 다른 사용자 화면에서 `다른 사람에게 배정됨`으로 표시됩니다. 10초 안에 시작하지 않으면 배정이 취소됩니다.
- 배정된 기기와 다른 빈 기기를 시작해도 사용할 수 있으며, 선택한 종류 안에서라면 기존 배정을 해제하고 실제로 시작한 기기를 사용 세션에 연결합니다. 다른 사용자에게 배정된 기기나 선택하지 않은 종류는 시작할 수 없습니다.
- 한 번 배정받으면 해당 세션에서 한 대만 시작할 수 있습니다. 세탁물을 회수한 뒤 `새로 배정받기`를 눌러 세탁기/건조기를 다시 선택하면 다음 기기를 사용할 수 있습니다.
- `로그아웃`하면 미사용 배정은 해제됩니다. 이미 시작한 세탁은 유지되며, 같은 학번과 이름으로 다시 입력하면 해당 세션을 이어갈 수 있습니다.
- 세탁기 4대와 건조기 4대를 사용할 수 있고, 세탁과 건조는 시연을 위해 각각 10초 동안 작동합니다.
- 작동 종료 후 10초가 지나면 다른 사용자가 `강제 회수`를 눌러 기기를 비울 수 있습니다. 미회수 바구니에는 모든 사용자의 세탁물이 표시되며, 본인 세탁물만 회수할 수 있습니다.
- 기기와 회수 상태는 1초마다 갱신됩니다.
- 데이터는 `data/state.json`에 저장되며 서버를 다시 시작해도 유지됩니다.
- 다른 기기에서 접속하려면 서버 PC의 IP 주소와 3000번 포트를 사용합니다. 방화벽 설정이 필요할 수 있습니다.

## 관리자

`/admin`에서 관리자 화면을 엽니다. 비밀번호는 `ADMIN_PASSWORD` 환경 변수에 설정합니다. 로컬에서는 Git에 포함되지 않는 `.env` 파일을 사용하고, 배포 환경에서는 환경 변수로 설정합니다. 비밀번호를 설정하지 않으면 관리자 로그인을 사용할 수 없습니다.

- 사용 중인 기기를 관리자가 해제할 수 있습니다.
- 관리자 세션은 8시간 후 만료되며, 로그인 실패가 5회 누적되면 1분 동안 로그인이 제한됩니다.

## Render 배포

Node Web Service를 생성하고 시작 명령으로 `npm start`를 설정합니다. Node.js 22.17 이상이 필요하며 외부 패키지는 사용하지 않습니다.

환경 변수:

- `ADMIN_PASSWORD`: 관리자 비밀번호
- `DATA_DIR`: 데이터 저장 경로. 영구 저장이 필요하면 Persistent Disk 경로(예: `/var/data/laundry`)를 설정합니다.

Render 기본 파일 시스템은 임시 저장소이므로 재배포 후 데이터가 사라질 수 있습니다. 데이터를 유지하려면 Persistent Disk가 필요합니다.

자세한 안내: https://render.com/docs/disks
